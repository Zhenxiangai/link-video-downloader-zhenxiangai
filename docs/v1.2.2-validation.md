# v1.2.2 validation / 发布验证

## Publicly reproducible / 公开可复现

Run from the repository root:

```bash
shellcheck scripts/bootstrap.sh
python3 -m py_compile scripts/wechat_archive.py tests/test_channel_delivery_finalization.py tests/test_bootstrap_remote_routing.py tests/test_official_batch_resilience.py
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -p 'test_*.py' -q
git diff --check
```

Verified result before release:

- 106 tests passed.
- The 600-job recovery test uses the real finalization path: it moves 600 local MP4 files, writes 600 output records, completes 600 manifests, and confirms that a second worker pass does not process them again.
- Dedicated tests cover delayed file visibility, stable-size detection, ambiguous files, paths outside the controlled job directory, failed-job recovery, and terminal creator-parent reconciliation.
- A crash-injection test interrupts recovery after the MP4 move but before the transcribing manifest write, then verifies local-only restart and terminal marker cleanup.
- Bootstrap tests cover CA certificate verification, backend-normalized certificate filenames, matching cleanup paths, and existing proxy cleanup safeguards.

发布前已验证：

- 106 项测试全部通过。

## Scope and limitations / 边界与限制

- The private replay validates candidate discovery against files that already exist. It does not re-download the 600 videos or rerun transcription.
- The reproducible 600-job test validates state transitions, file moves, output records, idempotence, and no backend call during local recovery.
- Certificate command semantics were checked against the macOS `security verify-cert` option contract. Release validation did not modify the login keychain.
- Platform behavior can still change after release; this evidence does not promise permanent compatibility with future WeChat versions.

- 私有重放验证的是现有文件的候选识别，没有重新下载 600 个视频，也没有重新转写。
- 公开可复现的 600 任务测试验证状态转换、文件移动、输出记录、幂等性，以及本地恢复不调用后端。
- 证书命令已按 macOS `security verify-cert` 参数契约核对；本次发布验证没有修改登录钥匙串。
- 平台后续仍可能变化，本证据不承诺永久兼容未来微信版本。
